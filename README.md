# Дашборд по вебинарам

Веб-приложение для анализа данных участников вебинаров с использованием Vue 3 и FSD архитектуры.

## 🚀 Быстрый старт

### Установка зависимостей

```bash
npm install
```

### Запуск приложения

Запустите backend сервер (в первом терминале):
```bash
npm run dev:server
```

Запустите frontend (во втором терминале):
```bash
npm run dev
```

Приложение:
- Frontend: http://localhost:5173
- Backend API: http://localhost:3000

### Сборка для продакшена

```bash
npm run build
```
