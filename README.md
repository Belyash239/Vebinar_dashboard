# Дашборд по вебинарам



## ✨ Основные возможности

- 📊 Аналитика по вебинарам и участникам
- 🔄 **Унифицированный импорт** - автоматическое определение формата (МТС-линк / Proofix)
- 📥 Единое drag & drop поле для всех файлов
- 🏷️ Система тегов для категоризации вебинаров
- 💬 Анализ чата и вопросов
- 📈 Статистика по компаниям и участникам
- 📤 Экспорт данных в Excel

## 🚀 Быстрый старт

### Установка зависимостей

```bash
npm install
```

### Запуск приложения

Запустите backend сервер (в первом терминале):
```bash
npm run dev:server
```

Запустите frontend (во втором терминале):
```bash
npm run dev
```

Приложение:
- Frontend: http://localhost:5173
- Backend API: http://localhost:3000

### Сборка для продакшена

```bash
npm run build
```
