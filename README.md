# Дашборд по вебинарам

Веб-приложение для анализа данных участников вебинаров с использованием Vue 3 и FSD архитектуры.

## 🚀 Быстрый старт

### Установка зависимостей

```bash
npm install
```

### Запуск приложения

Запустите backend сервер (в первом терминале):
```bash
npm run dev:server
```

Запустите frontend (во втором терминале):
```bash
npm run dev
```

Приложение:
- Frontend: http://localhost:5173
- Backend API: http://localhost:3000

### Сборка для продакшена

```bash
npm run build
```

## 📁 Структура проекта (FSD)

```
src/
├── app/                    # Инициализация приложения
├── pages/                  # Страницы
├── widgets/                # Композитные блоки
├── features/               # Функциональные возможности
├── entities/               # Бизнес-сущности
└── shared/                 # Переиспользуемый код
```

## 🎯 Текущий функционал

- ✅ Главная страница со списком вебинаров из БД
- ✅ Модальное окно импорта данных
- ✅ Загрузка и парсинг 3 типов файлов (.xlsx)
- ✅ SQLite база данных
- ✅ Backend API (Express)
- ✅ Сохранение данных в БД
- ✅ Выбор тегов для вебинара
